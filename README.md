# MouseHome v3.8

MouseHome is a small Android utility developed for the **TranSpeed
8K618-T Android TV Box** running **Android TV OS 12 / BigdroidOS
2.0.1**.

It was created for using the TV box with a standard wireless USB mouse
when the original remote control is unavailable or inconvenient.

## Main Features

MouseHome adds a HOME function to the middle mouse button (scroll
wheel):

-   **Short middle-button click:** remains unchanged and can continue to
    work as OK / Select.
-   **Long middle-button press (about 1 second):** sends the Android
    **HOME** command.
-   **START / STOP state is saved** and survives a reboot.
-   After boot, MouseHome respects the saved START / STOP setting.
-   After the automatic boot launch, the TV box returns to the Android
    HOME screen.
-   When MouseHome is opened manually, it stays on the application
    screen so START / STOP can be changed and the current setting can be
    viewed.

## Tested Device

MouseHome v3.8 was developed and tested on the following configuration:

-   **TV Box:** TranSpeed 8K618-T
-   **RAM / Storage:** 4 GB / 32 GB
-   **Operating System:** Android TV OS 12
-   **ROM / User Interface:** BigdroidOS 2.0.1
-   **Android Security Patch:** February 5, 2022
-   **Mouse:** SIGMACHIP USB wireless mouse

On the tested box, the mouse is available as:

``` text
/dev/input/event2
```

> **Important:** MouseHome v3.8 is specifically configured to monitor
> `/dev/input/event2`. On another Android TV box, or when using
> different USB hardware, the mouse may be assigned another input
> device. In that case, the source code may need to be modified.

## Root Requirement

MouseHome requires **root access (`su`)**.

Root access is used to:

1.  Read raw Linux mouse input events.
2.  Monitor the middle mouse button.
3.  Send Android `KEYCODE_HOME`.

You can check root access through ADB:

``` powershell
adb shell su -c id
```

On the tested TranSpeed box, the result contains:

``` text
uid=0(root)
```

If `su` root access is not available, MouseHome will not work as
designed.

## How MouseHome Works

MouseHome monitors the Linux input events generated by the USB mouse.

The middle mouse button generates `BTN_MIDDLE` DOWN and UP events.

The program uses the following logic:

-   If the middle button is released before approximately one second,
    MouseHome does nothing and the normal middle-click behavior is
    preserved.
-   If the middle button remains pressed for approximately one second,
    MouseHome sends:

``` text
KEYCODE_HOME
```

This returns Android TV to its HOME screen.

## Configure Automatic Startup

The tested BigdroidOS installation includes a built-in application
called **Autostart app**.

Open **Autostart app** and configure it as follows:

-   **Autostart app:** ON
-   **Sleep on:** OFF
-   **Only if Internet connected:** OFF
-   **Choose your app:** `MouseHome v3.8`

This allows BigdroidOS to launch MouseHome automatically after the TV
box boots.

## START and STOP

MouseHome provides two buttons.

### START MOUSEHOME

Pressing **START MOUSEHOME**:

-   Enables the long-middle-press HOME function.
-   Saves the START / ENABLED setting.

After the next reboot:

1.  BigdroidOS Autostart opens MouseHome.
2.  MouseHome reads the saved START setting.
3.  The mouse listener is started.
4.  MouseHome returns automatically to the Android HOME screen.

### STOP MOUSEHOME

Pressing **STOP MOUSEHOME**:

-   Stops the long-middle-press HOME function.
-   Saves the STOP / DISABLED setting.

After the next reboot:

1.  BigdroidOS Autostart opens MouseHome.
2.  MouseHome reads the saved STOP setting.
3.  The mouse listener remains stopped.
4.  MouseHome returns automatically to the Android HOME screen.

## Opening MouseHome Manually

When MouseHome is opened manually during normal operation, it remains on
its own screen.

This allows the user to:

-   View the saved/current MouseHome state.
-   Press **START MOUSEHOME**.
-   Press **STOP MOUSEHOME**.

It does not immediately return to HOME when opened manually.

## Building from Source

MouseHome v3.8 was developed using:

-   **JDK:** Eclipse Temurin JDK 17
-   **Gradle:** 8.7
-   **Android Gradle Plugin:** 8.5.2
-   **compileSdk:** 35
-   **Android SDK path used during development:** `C:\Android`

The project includes a PowerShell build script named:

``` text
build.ps1
```

To build:

``` powershell
cd C:\path\to\MouseHome
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

After a successful build, the APK is located at:

``` text
app\build\outputs\apk\debug\app-debug.apk
```

Install the newly built APK with:

``` powershell
adb install -r "app\build\outputs\apk\debug\app-debug.apk"
```

## Compatibility Notes

MouseHome was created for a specific TranSpeed / BigdroidOS
configuration and is **not guaranteed to work unchanged on other Android
TV devices**.

Other devices may differ in:

-   Root (`su`) availability.
-   Linux input device number.
-   Mouse event codes.
-   Android security restrictions.
-   Boot behavior.
-   Availability of the BigdroidOS **Autostart app**.

If the mouse is not `/dev/input/event2`, the input device should be
identified before modifying the source code.
